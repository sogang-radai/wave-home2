SleepNet model versions
=======================

Script suffix (e.g. 0-0, 0-1) is the version of that script file, not a per-model
namespace. A model run is identified by MODEL_TAG under training/ and models/.

Dataset
-------
  Raw PCR   : sleep-net/dataset/set0/   (see dataset/set0/info.txt)
  Pickle    : sleep-net/samples/set0-{N}.pkl

Shared encoder
--------------
  PointNetV1 frame encoder (256-d embedding per frame), shared by bed-net and toss-net.

Model matrix
------------

  MODEL_TAG      Temporal head   Bed window   Toss window   Preprocess           Training        Network              Export
  -------------  --------------  -----------  ------------  -------------------  --------------  -------------------  ------------
  sleep-net0-0   1D-CNN + AMP    160 (~8 s)   40  (~2 s)    preprocess_set0-0    training0-0     PointNetV1nCNNV1     export0-0
  sleep-net0-1   LSTM + mean     160 (~8 s)   40  (~2 s)    preprocess_set0-0    training0-1     PointNetV1nLSTMV1    export0-1
  sleep-net0-2   LSTM + mean     100 (~5 s)   40  (~2 s)    preprocess_set0-1    training0-2     PointNetV1nLSTMV1    export0-2

  sleep-net0-0 : baseline; TemporalCNNV1 uses AdaptiveMaxPool1d (spike-sensitive).
  sleep-net0-1 : same windows as 0-0; uni-directional LSTM + temporal mean pool.
  sleep-net0-2 : shorter bed window for faster status response; same LSTM heads.

Pickle outputs
--------------
  set0-0.pkl : from preprocess_set0-0.py  (BED_WINDOW=160, TOSS_WINDOW=40)  ~898 MB
  set0-1.pkl : from preprocess_set0-1.py  (BED_WINDOW=100, TOSS_WINDOW=40)  ~898 MB

  PCR decompression requires lzav. On macOS arm64:
    thirdparty/lzav/build.sh  ->  bin/arm64/lzav_lib.dylib
  On Windows x64, build lzav_lib.cpp similarly to bin/x64/lzav_lib.dll.

Training outputs (per MODEL_TAG)
--------------------------------
  sleep-net/training/{MODEL_TAG}/best_model.pth
  sleep-net/training/{MODEL_TAG}/checkpoint.pth
  sleep-net/training/{MODEL_TAG}/logs/summary_log.csv

Export outputs (per MODEL_TAG)
------------------------------
  sleep-net/models/{MODEL_TAG}/pointnet.onnx + pointnet.ncnn.param/.bin
  sleep-net/models/{MODEL_TAG}/bed_{cnn|lstm}.onnx + .ncnn.param/.bin
  sleep-net/models/{MODEL_TAG}/toss_{cnn|lstm}.onnx + .ncnn.param/.bin
  sleep-net/models/{MODEL_TAG}/model.json   (generated by export script)

Typical workflow
----------------
  1. python scripts/preprocess_set0-0.py     # once; produces set0-0.pkl
  2. python scripts/preprocess_set0-1.py   # once; produces set0-1.pkl
  3. python scripts/training0-0.py           # Colab or local GPU
  4. python scripts/export0-0.py
     ... repeat 0-1 / 0-2 for LSTM variants

Inference (wave-server)
-----------------------
  Deploy model.json + ncnn weights to bin/models/sleep/ or a versioned folder.
  temporal_aggregator.type : "1dcnn" (0-0) or "lstm" (0-1, 0-2)
