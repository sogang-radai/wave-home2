# 데모 채팅(WaveAI) 기능 명세

- 작성일: 2026-07-13
- 대상 빌드: `site-demo` (`REACT_APP_API_MODE=demo`) + `wave-server --profile demo`
- 관련 코드: `src/wave-server/web/demo_policy.cpp`, `src/wave-server/demo/*`, `wave-home-agent/app/graph/tools.py`, `wave-home-front/src/api/demo/*`

## 1. 데모 모드 개요

### 1.1 실행 구성


| 구성 요소  | 역할                             | 기본 포트 / 경로                      |
| ------ | ------------------------------ | ------------------------------- |
| 프론트엔드  | `site-demo` SPA, API 모드 `demo` | wave-server document root       |
| 백엔드    | `wave-server --profile demo`   | **8502**                        |
| 에이전트   | LangGraph 채팅·툴 실행              | **8501** (코어 API를 8502로 향하게 설정) |
| 데이터베이스 | `bin/data/demo.db`             | **read_only** (영구 기록 없음)        |


데모는 실물 장치 매니저를 켜지 않습니다(`devices_enabled: false`). 대신 **브라우저별 가상 장치·세션 상태**로 IoT 제어·예약·알람을 시연합니다.

포트·`/internal`·세션/DB 불변식의 SSOT: [`wave-server-boundaries.md`](./wave-server-boundaries.md).

### 1.2 시연 세션 (`demoRuntimeId`)

- 브라우저마다 `demoRuntimeId`가 발급됩니다 (쿠키 / `X-Wave-Demo-Runtime-Id` 헤더).
- 채팅 대화, 가상 장치 상태, 알람·일정·자동화 룰, AI 개인 프롬프트 등은 **해당 세션 메모리에만** 반영됩니다.
- SQLite(`demo.db`)에는 쓰지 않습니다. 새로고침·세션 만료 후 공유 DB 원본으로 돌아갑니다.
- 여러 시연자가 동시에 써도 서로의 조작이 섞이지 않도록 격리됩니다.



### 1.3 달력·시간

- **앵커 날짜**: `2026-06-30` (수면·전력 리포트 등 조회 기준일 고정).
- 시계 시각(시·분·초)은 실제 시간을 사용합니다. 예약·알람 발화 시각은 이 시계를 따릅니다.



### 1.4 정책 요약


| 구분                                   | 동작                       |
| ------------------------------------ | ------------------------ |
| 채팅·조회(수면/전력/DB/RAG)                  | 허용                       |
| 가상 장치 제어·알람·일정·룰 (세션)                | 허용                       |
| 그 외 API 변경(계정/방/장치 CRUD, IR 학습 저장 등) | **403** `DEMO_READ_ONLY` |
| 프론트 일부 쓰기 UI                         | `demoGuard`로 차단 + 안내     |

## 2. 채팅 UI에서 쓸 수 있는 기능

데모 채팅은 프로덕션과 동일한 **실시간(SSE) WaveAI**를 사용합니다 (`api/demo/ChatApi` → `api/v1/ChatApi`).

### 2.1 대화·화면


| 기능            | 설명                                     |
| ------------- | -------------------------------------- |
| 전체 화면 채팅      | WaveAI 페이지에서 대화                        |
| 팝업(작게 보기)     | 채팅을 축소 팝업으로 유지하며 다른 화면과 병행             |
| 대화 목록         | 대화 선택·추가·이름 변경·삭제·고정 (세션 범위)           |
| 스트리밍 응답       | 토큰 단위로 답이 표시됨                          |
| 도구 실행 표시      | DB 조회·기기 제어 등 툴 호출을 칩/로그로 표시           |
| 생각 과정         | 모델이 reasoning을 보내면 접을 수 있는 “생각 과정” 영역  |
| 마크다운          | 굵게·기울임·코드·목록·표 등 (이미지 `![]()` 렌더는 미지원) |
| 시연 모드 안내      | 빈 채팅에 시연용 안내 배너 표시                     |
| 상단 “시연 모드” 배지 | TopBar에서 시연 상태 표시                      |




### 2.2 입력·설정


| 기능         | 설명                                         |
| ---------- | ------------------------------------------ |
| 텍스트 전송     | Enter 또는 Ctrl/⌘+Enter (설정에 따름)             |
| 환영 제안 칩    | 클릭 시 해당 프롬프트로 질문 시작                        |
| 인사이트 제안    | 수면·전력·심박 관련 빠른 질문                          |
| AI 개인 프롬프트 | 설정 → AI 에이전트에서 지정. 매 턴 시스템 메시지로 주입 (세션 저장) |
| 모델·전송 키 설정 | 데모에서도 AI 에이전트 설정 API는 허용                   |




### 2.3 환영·인사이트 예시 문구 (기본 시드)

**인사이트**

- 오늘 수면 인사이트 알려줘
- 이번 주 전력 사용량 어때?
- 오늘 심박수 어때?

**환영 제안**

- 어젯밤 수면 점수를 분석해줘
- 지금 집 전체 전력 사용량 알려줘
- 오늘 심박수가 평소와 다른 이유가 뭐야?
- 취침 전 가전 자동화 설정 도와줘
- 이번 주 건강 목표를 세워줘
- 더 깊은 수면을 위한 실내 환경 알려줘
- 수면에 최적인 실내 온도가 몇 도야?
- 에너지 점수를 높이는 방법 알려줘



### 2.4 디지털 트윈과 연동 (채팅 결과의 시각화)

Home Twin 화면이 열려 있을 때:

- 채팅으로 가전을 제어하면 **트윈 모델에 즉시 반영**됩니다.
- 알람 TTS/사운드 계열은 **실제 스피커 재생 대신** 트윈 **말풍선(speech overlay)** 으로 표시될 수 있습니다.
- Twin 상단 코치 말풍선에 시연용 예시 문장이 제공됩니다.

**트윈 코치 예시**


| 주제     | 예시 발화                            |
| ------ | -------------------------------- |
| 전원     | 거실 선풍기 꺼줘                        |
| 조명 색   | 침실 조명을 따뜻한 주황색으로 바꿔줘             |
| 색온도    | 부엌 화이트 조명 색온도를 2700K로 맞춰줘        |
| 밝기     | 침실 조명 밝기를 40%로 낮춰줘               |
| TTS 알람 | Wave Station으로 "일어날 시간이에요"라고 말해줘 |
| 예약     | 매일 밤 11시에 침실 TV 끄도록 예약해줘         |
| 트리거    | 손 흔들면 거실 조명 켜지게 자동화 만들어줘         |


> 참고: TTS·제스처 트리거 **룰 생성**은 가능하나, 데모에서는 실스피커 재생·실제스처 발화가 제한됩니다(§5).

## 3. 에이전트 도메인·도구

에이전트는 질문을 **도메인**으로 라우팅한 뒤, 도메인별 툴 부분집합을 사용합니다.


| 도메인       | 주요 용도          | DB/RAG 범위(요약)                                                   |
| --------- | -------------- | --------------------------------------------------------------- |
| `sleep`   | 수면 점수·리포트·인사이트 | `sleep_session`, `sleep_stat`, `sleep_report`                   |
| `power`   | 전력·에너지·리포트     | `power_energy`, `power_report`                                  |
| `posture` | 제스처 세트·로그 조회   | `gesture_set`, `gesture_log`                                    |
| `iot`     | 장치·예약·알람·자동화   | `device`, `room`, `alarm`, `schedule_task`, `automation_rule` 등 |
| `general` | 복합 질문          | 전체 툴셋                                                           |




### 3.1 채팅에서 호출 가능한 도구 목록

아래 도구는 데모에서도 **도구 자체는 노출**됩니다. 실행 결과는 가상 세션·mock DB·제한 사항에 따릅니다.


| 도구 이름                                     | 사용자 관점 기능           | 데모에서의 실효                       |
| ----------------------------------------- | ------------------- | ------------------------------ |
| `query_db`                                | mock DB 구조화 조회      | **사용 가능**                      |
| `rag_search`                              | 리포트·문서 유사도 검색       | **사용 가능** (벡터 없으면 텍스트 폴백)      |
| `list_devices`                            | 장치 목록               | **사용 가능**                      |
| `get_device_classes`                      | 장치 클래스·액션 카탈로그      | **사용 가능**                      |
| `get_device_capabilities`                 | 장치별 지원 액션/쿼리        | **사용 가능**                      |
| `control_device`                          | 전원·밝기·색·볼륨·IR 송신 등  | **사용 가능** (세션 상태)              |
| `query_device` / `get_device_state`       | 실시간(가상) 상태·전력량 등    | **사용 가능**                      |
| `schedule_device_action`                  | 시각 기반 예약 자동화        | **사용 가능** (시간 트리거 발화)          |
| `automate_device_action`                  | 제스처·상태·IR 등 이벤트 자동화 | **룰 생성만** (이벤트 발화 제한, §5)      |
| `list_schedules` / `cancel_schedule`      | 예약/룰 목록·취소          | **사용 가능** (세션)                 |
| `get/create/update/delete_schedule_task`  | 주간·1회 일정 CRUD       | **사용 가능** (세션)                 |
| `get/create/update/delete_alarm`          | 알람 CRUD             | **사용 가능** (세션, 시각 도래 시 발화)     |
| `list_ir_commands` / `get_ir_command`     | IR 명령 목록·상세         | **사용 가능** (`ir_list.json`)     |
| `execute_rule` / `set_rule_enabled`       | 룰 수동 실행·활성 전환       | **사용 가능** (세션)                 |
| `list_events`                             | 장치 이벤트 조회           | **제한** (실기기 이벤트 스트림 없음)        |
| `get_ptz_capabilities` / `ptz_*`          | 카메라 팬·틸트·줌          | **제한** (실카메라 없음, 트윈 POV는 UI 목) |
| `get_camera_stream` / `set_camera_stream` | 스트림 on/off          | **제한** (플레이스홀더 영상)             |
| `send_camera_tts`                         | 장치 TTS 재생           | **사실상 불가** (실장치·TTS 엔진 경로 없음)  |

## 4. 기능 영역별 상세



### 4.1 수면·건강 Q&A

**가능**

- 어젯밤/특정일 수면 점수·단계·리포트 설명
- 심박·호흡 등 mock 데이터 기반 트렌드·원인 설명
- RAG로 수면 리포트 문맥 검색
- 수면 환경(온도 등)에 대한 일반·데이터 기반 조언

**제한**

- 수면 설정·레이더 파이프라인 **실측 재분석 쓰기**는 데모에서 막힘
- 달력은 앵커 날짜 기준으로 해석

**예시 발화**

- 어젯밤 수면 점수를 분석해줘
- 오늘 심박수가 평소와 다른 이유가 뭐야?
- 더 깊은 수면을 위한 실내 환경 알려줘



### 4.2 전력·에너지 Q&A

**가능**

- “지금” 집 전체·플러그별 전력: 가상 플러그의 **실시간(시뮬) 전력** 조회
- 과거 사용량·리포트: mock DB / RAG
- 절전·에너지 점수 관련 조언

**제한**

- 전력 인사이트 **승인(approve)** 등 일부 UI 쓰기는 `demoGuard`로 차단

**예시 발화**

- 지금 집 전체 전력 사용량 알려줘
- 이번 주 전력 사용량 어때?
- 에너지 점수를 높이는 방법 알려줘



### 4.3 IoT 가전 제어 (가상 장치)

시연용으로 제어·조회되는 대표 클래스:


| 클래스                            | 시연 가능 동작(요약)                      |
| ------------------------------ | --------------------------------- |
| `tuya_ep2h` (스마트 플러그)          | on/off/toggle, 전력·전압·전류·에너지 조회    |
| `philips_wiz_e29_color`        | 전원, 밝기, 색온도, RGB 색                |
| `philips_wiz_e29_white`        | 전원, 밝기, 색온도                       |
| `samsung_g7` / Tizen TV        | 전원, 볼륨±, 채널±, 뮤트, 앱 실행·리모컨 키(ACK) |
| `wave_station`                 | 구독 상태, `send_ir` (세션에 마지막 명령 기록)  |
| `srs_r4sn` (레이더)               | presence/posture 등 **조회** 중심      |
| `reolink_e1_pro` / `droid_cam` | 스트림 플래그 수준 (실영상·실TTS 제한)          |


**예시 발화**

- 거실 선풍기 꺼줘
- 침실 조명 밝기를 40%로 낮춰줘
- 침실 TV 볼륨 올려줘

제어 결과는 IoT 제어 패널 상태와 **디지털 트윈**에 반영됩니다.

### 4.4 예약(스케줄)·일정 태스크

**가능**

- “매일 밤 11시에 …” 형태의 **시간 기반 예약** 생성
- 주간/1회 `schedule_task` CRUD
- 예약 목록 조회·취소
- `DemoAutomationRuntime`이 주기적으로 시각을 확인해 **시간 조건 룰을 발화**

**제한**

- DB에 영구 저장되지 않음 (세션만)
- 시연 종료·세션 만료 시 소멸

**예시 발화**

- 매일 밤 11시에 침실 TV 끄도록 예약해줘
- 취침 전 가전 자동화 설정 도와줘



### 4.5 알람

**가능**

- 알람 생성·수정·삭제·조회
- 시각 도래 시 세션 알람 실행 (알림·방법: 조명/플러그/TTS 오버레이 등)

**제한**

- 실제 Wave Station 스피커 TTS 오디오는 재생되지 않을 수 있음 → 트윈 말풍선/알림으로 대체
- 세션 전용

**예시 발화**

- 내일 아침 7시에 기상 알람 맞춰줘
- Wave Station으로 "일어날 시간이에요"라고 말해줘 *(의도 전달은 가능, 실재생은 제한)*



### 4.6 이벤트 자동화 (제스처·IR·장치 상태)

**가능**

- “손 흔들면 조명 켜줘”처럼 **자동화 룰 생성·저장(세션)·수동 실행·활성 전환**

**제한**

- 실레이더 제스처·실IR 수신·실장치 상태 변화로 인한 **자동 발화는 동작하지 않음** (`no_devices`로 트리거 런타임 미기동)
- 시연에서는 “룰이 만들어졌는지”와 시간 기반 예약 발화를 중심으로 보여주는 것이 적합



### 4.7 IR

**가능**

- IR 명령 카탈로그 조회
- Wave Station 가상 장치에 `send_ir` 제어 (세션에 송신 기록)

**제한**

- UI에서 IR 학습·저장·테스트 전송은 `demoGuard` / 정책으로 차단
- 실제 IR 하드웨어 TX/RX 없음



### 4.8 카메라·TTS


| 항목                           | 데모                   |
| ---------------------------- | -------------------- |
| 카메라 미리보기                     | 플레이스홀더/POV 수준        |
| PTZ                          | 실장비 없음 (트윈/UI 목업 수준) |
| `send_camera_tts` / 실스피커 TTS | **불가 또는 실패**         |


채팅으로 TTS를 요청해도 프로덕션처럼 장치에서 음성이 나오지 않는 것이 정상 시연 범위입니다.

### 4.9 자세(Posture)

- 채팅 도메인상 `gesture_set` / `gesture_log` **조회**는 가능합니다.
- 사이드바 **자세 페이지는 데모에서 숨김** 처리됩니다.



### 4.10 주간 목표·코칭

- 채팅으로 건강 목표를 “세워 달라”는 대화는 가능합니다.
- Goals API persistence는 데모에서 목/가드 성격이 강하므로, **영구 저장을 기대하지 않는 시연**으로 안내합니다.
