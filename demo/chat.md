# 데모 채팅 시나리오 (검수용)

데모 `chat_history`를 **실제 에이전트 턴 + 툴콜**로 다시 채우기 위한 시나리오 초안입니다.
앵커 시각은 `bin/config.json` 데모와 동일하게 **2026-06-30** 고정입니다. 사용자 대사에서는 「6월」을 빼고 **「18일」「25일」**처럼만 말해도 에이전트가 알아듣게 합니다.
주 사용자: **김건강**(`user_id=1`). 박헬스(`user_id=2`)는 침실 수면 데이터가 없으므로 IoT·전력 공용 시나리오에만 일부 사용합니다.

용어: UI/사용자 말투에서는 **자동화**(내부 테이블 `automation_rule`), **기상 맞춤 알람**(내부 `smart_wake`).

관련 데이터: [`sleep.md`](./sleep.md), [`power.md`](./power.md), [`demo.md`](./demo.md)  
에이전트 툴: [`docs/agent-api/`](../docs/agent-api/README.md)

## 작업 방식 (합의)

1. 이 문서에 **주제별 시나리오 + 첫 사용자 대사**를 고정한다 (검수).
2. 시나리오마다 JSON 시드 파일을 두고, 첫 대사를 수동으로 넣는다.
3. Python 스크립트로 데모 세션(에이전트 :8512 + 백엔드 :8510)을 돌려 **응답·툴콜**을 수집한다.
4. 수집된 답을 보고 다음 사용자 대사를 작성 → 2~8턴 채울 때까지 반복한다.
5. 시나리오 시작 전 **장치 상태**를 각 시나리오의「초기 상태」에 맞게 맞춘다.

> 턴 수는 목표치입니다. ±1턴 조정 가능.

- [ ] 날짜가 「18일」「25일」처럼만 나와도 앵커(6/30)와 맞는지
- [ ] 「자동화」「기상 맞춤 알람」용어가 통일됐는지
- [ ] 카메라/PTZ 시나리오가 없는지
- [ ] 빼고 더할 ID

수집(턴 단위, 답을 보고 다음 대사 입력):

```bash
python3 demo/scripts/06_collect_chat_turns.py reset          # chat.json 삭제
python3 demo/scripts/06_collect_chat_turns.py start S01      # 첫 대사
python3 demo/scripts/06_collect_chat_turns.py turn S01 "…"   # 답 보고 다음 대사
python3 demo/scripts/06_collect_chat_turns.py done S01
python3 demo/scripts/06_collect_chat_turns.py status
```

산출: `demo/agent/chat.json`
